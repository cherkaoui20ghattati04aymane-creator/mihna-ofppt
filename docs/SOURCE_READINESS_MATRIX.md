# Phase 11.5 source readiness matrix

Reviewed 24 November 2026 UTC. “Unverified” fields remain unknown. Source approval applies to the specific data and access method described.

| Source and coverage | Status | Access, terms, limits, data and decision |
|---|---|---|
| [Jobicy](https://github.com/Jobicy/remote-jobs-api#fair-use), international remote | VERIFIED_FREE_WITH_CONDITIONS | Public REST and RSS, no key or charge on public routes. Fair Use allows use in own products with attribution and canonical link. At most one sync per hour, up to 200 feed rows per cursor and 100 IDs per status batch. Seven-day publication window. Country eligibility, publication date, employer, optional salary, no inferred expiry. Mihna caps discovery at two 20-row pages and verifies activity separately. |
| [GLEIF](https://www.gleif.org/en/lei-data/gleif-api/) and [CC0 terms](https://www.gleif.org/en/meta/lei-data-terms-of-use/), Moroccan legal identities | VERIFIED_FREE_AND_AUTHORIZED | Public JSON:API and downloads, no key. Used a Morocco legal-address filter and two pages. No rate quota assumed. Legal names, LEI, registered city and registration status. No vacancies, salary, verified worksite or inferred employer links. Search is offline against an attributed snapshot. |
| [Wadifa Info](https://www.wadifa-info.com/developpeurs), Moroccan public competitions | VERIFIED_FREE_WITH_CONDITIONS | Keyless public JSON, RSS, calendar and exports. CC BY 4.0 with visible follow link to each source item. Maximum one request per minute, hourly update, up to 2,000 concours. Publication, deadline, posts, employer and official notice when supplied. Dates and posts ultimately come from official notice. No salary or location inferred from an employer name. |
| [Himalayas](https://himalayas.app/docs/remote-jobs-api), international and Morocco-eligible remote | VERIFIED_FREE_WITH_CONDITIONS | Keyless public JSON and RSS, optional free key with higher limits. Listing attribution and API application links, daily checks, no onward syndication. Cursor pages up to 20. Public individual job status allows 60/minute. Listings have publication, expiry and optional salary and geographic restrictions. |
| [Emploi-public.ma](https://www.emploi-public.ma/fr/content/mention-legale), official administration and public entities | PUBLIC_ACCESS_REQUIRES_TERMS_REVIEW | Official HTML with dates, vacancies and notices; terms describe personal consultation. Reuse of a direct automated feed, rates, and redistribution were not established. Manual link and notices referenced by Wadifa retained. |
| [ANAPEC](https://www.anapec.ma/), Moroccan employment | PUBLIC_ACCESS_REQUIRES_TERMS_REVIEW | Official public-facing service. No reusable bulk feed, licence, rate or pagination verified for Mihna. |
| [OFPPT](https://newweb.ofppt.ma/fr/trouver-un-emploi), stages and employment | PUBLIC_ACCESS_REQUIRES_TERMS_REVIEW | Official employment page returned an empty list on review. Licence, automated feed, rates and export unverified. |
| [Open Data Maroc](https://data.gov.ma/data/fr/dataset/?groups=emploi), labour-market and public-job aggregates | VERIFIED_FREE_WITH_CONDITIONS | Public catalogue and dataset-specific download permissions. ODbL applies where indicated. No suitable listing dataset verified; aggregated rows are not imported as jobs. |
| [Emploi.ma](https://www.emploi.ma/conditions-generales-utilisation), [ReKrute](https://www.rekrute.com/fr/mentions-legales.html), [Dreamjob.ma](https://www.dreamjob.ma/privacy-policy/) | AUTOMATION_NOT_AUTHORIZED | Public landing pages are distinct from collection rights. Emploi.ma prohibits robots; ReKrute restricts extraction; Dreamjob reproduction is private/personal only. No collection. |
| [Jawb](https://jawb.ma/en/api-recrutement), Morocco | PUBLIC_ACCESS_REQUIRES_TERMS_REVIEW | RSS and company-specific JSON are documented for employer publishing. Rights for Mihna aggregation and storage were not established. Existing gated adapters remain disabled without evidence. |
| [Capgemini](https://www.capgemini.com/ma-en/careers/join-us/), [Orange Maroc](https://orange.jobs/fr/fr/afrique-moyen-orient/maroc), [Maroc Telecom](https://www.iam.ma/en/groupe-maroc-telecom/carri%C3%A8res), [Attijariwafa bank](https://www.attijariwafabank.com/fr/emploi-carrieres), [OCP](https://careers.ocpgroup.ma/), [Tanger Med](https://www.tangermed.ma/fr/offre-d-emploi/) | PUBLIC_ACCESS_REQUIRES_TERMS_REVIEW | Official manual career routes across software, consulting, telecom, banking, industry and logistics. Listings and internships vary by site. No confirmed reusable feed, export, redistribution licence or applicable rate limit for the reviewed employers. |
| [Accor](https://careers.accor.com/global/en/morocco) and [Marriott](https://careers.marriott.com/jobs?filter%5Bcountry%5D%5B0%5D=Morocco), hospitality and Marrakech | PUBLIC_ACCESS_REQUIRES_TERMS_REVIEW | The official sites showed Morocco and Marrakech opportunities. Added manual links in Mihna. Feed licence and automated redistribution unverified; source listings were not copied. |
| [Remote First Jobs](https://remotefirstjobs.com/jobs-api) | BLOCKED_BY_ACCESS_RESTRICTIONS | Public API docs describe free access, attribution, five 100-row pages and delayed listings, but the live robots file disallows the JSON endpoint. RSS is documented separately; its basic items lack structured eligibility and status fields, so it was not imported into the verified catalog. |
| [Remotive](https://github.com/remotive-com/remote-jobs-api) | PUBLIC_ACCESS_REQUIRES_TERMS_REVIEW | Public delayed feed and source attribution rules. Terms restrict onward distribution and signup gating. Access compatibility with Mihna's authenticated catalog and current crawler policy was not established. |
| [Remote OK](https://remoteok.com/robots.txt) | NOT_YET_VERIFIED | Public robots file returned rules. A compatible reuse and display policy plus suitable Morocco eligibility fields were not established during this phase. |
| [CAPPRAfrica](https://skills.capprafrica.org/fr/nos-outils), [Jobsquare](https://www.jobsquare.ma/aide-recruteur/api-integrations/) | AUTHENTICATION_REQUIRED | API/export access or account integration requires provider approval, credentials or contract. No free authorized public aggregate feed established. |

For non-integrated candidates, authentication for human browsing, pagination, update interval, salaries, location accuracy, duplicate rate and final integration cost remain unverified where the provider did not document those details. None was inferred from the presence of a public page.
